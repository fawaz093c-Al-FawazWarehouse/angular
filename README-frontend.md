# AFW Angular Notifications Demo (Preview)

This preview is a lightweight Angular frontend demonstrating how users can subscribe to push notifications for products.

To run locally:
1. Fill `src/environments/environment.ts` based on `environment.ts.example`.
2. Add Firebase SDK snippets to `src/index.html` (already included in this demo).
3. ng serve

For a live preview, you can import this branch into StackBlitz or CodeSandbox (import GitHub repository branch) or I can create a StackBlitz instance for you.
